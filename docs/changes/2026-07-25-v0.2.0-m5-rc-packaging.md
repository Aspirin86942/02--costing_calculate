## Rollback boundary

The RC ZIP and its companion checksum form one immutable rollback unit:
executable, default config, both schemas, README, CHANGELOG, examples, and
checksums are kept together. The enhanced package smoke proves that this unit
can still start, preflight, and generate contract-valid GB/SK workbooks.

After M6 produces the final package, the rollback drill must deploy this RC
unit as the previous complete bundle and rerun the same smoke. It is not valid
to restore only the executable while retaining another version's config or
schemas.
