# v0.2.0 M6B ZIP Compression Experiment — 2026-07-25

## Decision

**Rejected; Level 5 retained.** Levels 3 and 2 both improved SK full-run wall
time and `xlsx_save`, preserved workbook semantics, and stayed within the PWS
guardrail. Both candidates nevertheless exceeded the frozen SK output-size
limit of `48,658,823` bytes. The PRD makes that limit a hard gate, so neither
candidate is eligible for adoption.

Level 1 was not tested because Level 2 exceeded the size limit by more than
8 MB and therefore had no sufficient size margin. Production remains at
`workbook.set_compression_level(5)`, and no contract baseline or threshold was
changed.

## Protocol

- one unmeasured normal-run warmup per binary for each candidate experiment;
- five formal SK pairs per candidate;
- odd pairs Level 5 then candidate, even pairs candidate then Level 5;
- independent processes with 50ms Peak Working Set polling;
- external wall, PWS, output bytes, output SHA-256, and every stage captured;
- runtime, quality, error-log, count, and Sheet-count contracts compared for
  every pair;
- same-directory low-memory temporary artifacts checked after each run;
- one fresh output from each rejected candidate compared with the final
  Level 5 workbook using the repository's full workbook comparator.

The comparator checks Sheet order, package relationships, shape, freeze panes,
filters, widths, styles, number formats, conditional formatting, cell values,
and business reconciliations. Raw timing logs and workbooks remain in ignored
local diagnostic directories; only this sanitized result is versioned.

## Level 1 skip

The PRD permits Level 1 only when Level 2 retains sufficient output-size
margin. Level 2 instead exceeded the frozen limit by `8,286,515` bytes.
Testing Level 1 would therefore add benchmark cost without a plausible
adoption path and was intentionally skipped.

## Rejection rationale

Compression Levels 3 and 2 provide real and repeatable save-time improvements,
but their output sizes violate the immutable P0 limit. Correctness, speed, and
PWS success cannot override that failure. Level 5 is therefore the only
eligible production setting from this experiment, and the M6B requirement is
complete with a documented rejection.
