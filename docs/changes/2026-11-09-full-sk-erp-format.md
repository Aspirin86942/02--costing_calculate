## 独立输入与金额审计

原文件为 `163,340,340 bytes`，一个工作表，XML 解压后 `1,504,725,639 bytes`。第 3/4 行为双层表头，共 58 列；实际最后一行为 912,925，期间为 2025-01 至 2026-10。导出文件错误声明的工作表范围为 `A1`。

独立 XML 扫描核对：

```text
912,921 = 1 合计行 + 19,390 材料汇总行 + 812,588 明细行 + 80,942 数量输入行
80,942 = 12,981 有效数量行 + 67,961 完工数量无效行
```

原先 12,969 个总成本差异与材料子项/ERP 汇总的差额完全一致。采用用户选择的 ERP 口径后，12,981 行有效数量记录的总成本勾稽均通过；12,969 个子项差异作为材料复核提示保留。另有 2 张有效工单的 ERP 材料汇总金额缺失，记录缺失金额提示并保留复核状态。

最终质量提示为 364,042 条：`MATERIAL_DETAIL_MISMATCH` 12,969 条、`MISSING_AMOUNT` 317,345 条、`NON_POSITIVE_UNIT_COST` 33,728 条。缺失金额中包含原始明细缺失 317,343 条和材料汇总缺失 2 条。总成本勾稽通过与整体数据校验状态分别表达，材料差异行仍显示“需复核”。
