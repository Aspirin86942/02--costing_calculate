## 已确认的异常位置

第一轮阶段诊断的测试、编译与合成烟测通过。完整 SK 前 5 次与参考结果一致，第 6 次在 core 处理完成、尚未进入 Excel 写出时发现 2 处非法 UTF-8 文本编码，以及 3 个包含 XML 控制字符的文字单元格。该次读取完成时的内容摘要正常。

第二轮增加了规范化、填充、拆分和聚合检查点。合成烟测的 27 个检查点通过；第一次完整 SK 在读取完成后已经出现 1 个控制字符，随后诊断断言终止。

将第二轮与第一轮的成功记录逐列对齐，得到：

| 检查位置 | 结果 |
|---|---|
| Calamine 解析出的 Range | 文字、Decimal 和浮点各列摘要一致，无控制字符 |
| 转换成 RawWorkbook 后 | 第 24、29 列文字摘要变化，新增 1 个控制字符；数值摘要及类型计数一致 |
| 转成 IndexedTable 后 | 同一控制字符仍存在，诊断终止 |

以上列号从 1 起算。最早观察窗口已经收窄到 Range 转换和结果保存期间；不同运行的首次发现位置不同，尚未证明某个具体业务函数存在缺陷。异常已经可以在写出前观察到。

## 脱离项目的复现

所有对照均只用生成数据和已有工具，无 ERP、Excel 库或新增生产依赖。出现数值变化时保留失败记录，未补选样本。

| 对照 | 结果 | 证据目录或文件 |
|---|---|---|
| 3 GiB 固定模式，只读 SHA-256，32 轮 | 未发现变化 | `baseline-localization-v1/memory-probe.json` |
| 3 GiB 地址不同的随机模式，只读 SHA-256，32 轮 | 未发现变化 | `baseline-localization-v1/random-memory-probe.json` |
| Rust 1.96，原始标准库探针，60 万行 | 首轮转换后发现变化；两次独立重放也失败 | `baseline-localization-v1/allocator-probe-summary.json`、`allocator-localization-v2/` |
| Rust 1.96，增加输入和逐单元格检查，关闭/开启优化、两种 String 转 Arc API | 4 项均发现变化，小型烟测均通过 | `allocator-localization-v2/` |
| 已装 Rust 1.99.1，同一冻结源码，原始及细分探针 | 5 项均发现变化，小型烟测均通过 | `toolchain-localization-v1/` |
| GCC 与 Clang，约 3 GiB 大块复制及逐字段复制，每项 2 轮 | 4 项均未发现变化 | `copy-localization-v1/` |
| GCC/C++ 标准容器，60 万行的小对象分配、构建与复制，关闭/开启优化 | 2 项均在首次完整转换检查中发现变化，小型烟测通过 | `small-allocation-control-v1/` |

C++ 探针只有生成数字和标准容器，不含字符串、Arc 或 Rust 依赖。每个数字同时保存逐位取反的备份；失败时二者已经失配。

Python 用独立的整数和浮点位转换重新计算了全部 9 个带详细数值的失败记录：预期值均符合生成规则，实际值均破坏取反关系，每个记录均为单比特变化。它们不能用正常的浮点尾数容差解释。

这组证据说明，业务代码、Calamine、写出库和 Rust 特有实现都不是复现现象的必要条件。共同的内存分配、系统与硬件运行路径仍需进一步区分；具体分配器、内核或硬件部件尚未被确认。大块内存检查通过只覆盖其各自访问模式。

## 读取路径评估

推荐的下一项候选是使用现有 Calamine `worksheet_cells_reader` / `next_cell` 逐个取得有效单元格，直接构建 RawWorkbook。Calamine 0.38.0 已提供接口，可以复用当前依赖。

当前调用链先构建稀疏单元格集合，再构建完整 Range，随后转成业务行。B1 仅改为借用 Range，仍保留完整二维容器；既有 6 对数据的逐对改善为 0.355%、胜出 3/6，峰值内存基本相同，未满足采纳门槛。

直接构建业务行的收益假设是减少中间容器、空单元格初始化与转换。尚未实现或测量该候选。进程峰值内存还受派生列扩容和后续处理影响，不能预先给出整体节省比例。

实现与验收边界已补入[优化计划](../plans/2026-11-11-memory-optimization.md)：双层表头、前置元数据、真实单元格范围、错误 A1 声明、稀疏列/空行、Decimal、日期、材料汇总及非 XLSX 路径均保持。基线的内容完整性得到独立验证后，才开始新的正式正确性与性能批次。
