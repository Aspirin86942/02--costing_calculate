# Costing Calculate v0.2.0-rc.1

This release candidate validates the Windows packaging, installation, audit,
and rollback chain before the two controlled performance experiments.

## Compatibility

- Rust is the production entry point; Python remains only for oracle and
  regression verification.
- The frozen GB/SK business rules, Decimal semantics, three-Sheet workbook,
  quality metrics, error-log behavior, console JSON, and exit codes are
  unchanged.
- External configuration can change only the reviewed product list/order and
  safe input pattern. Sealed cost and anomaly contracts remain immutable.

## Main changes

- Pinned Windows/Ubuntu CI and baseline governance.
- Deterministic build identity and exact Rust toolchain.
- Versioned configuration and semantic hashes.
- Optional success/failure run Manifest with input/output SHA-256 and path
  redaction.
- Atomic no-overwrite publication for workbook and Manifest outputs.
- Self-contained Windows ZIP with schemas, examples, and SHA-256 checksums.

## Known issues

- M6A `cell_text` and M6B ZIP-compression experiments are pending. This RC is
  not the final v0.2.0 build.
- A power loss or forced termination may leave diagnostic temporary files; a
  partial workbook is never published to the final path.

## Verification

Verify the downloaded ZIP with its `.zip.sha256` companion, then verify the
executable against the package's `SHA256SUMS`. Keep the executable,
configuration, schemas, and release notes together for rollback.
