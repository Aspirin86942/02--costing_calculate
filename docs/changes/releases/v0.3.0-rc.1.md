# Costing Calculate v0.3.0-rc.1

这是 v0.3.0 全项目整理的发布候选。

## 主要变化

- Rust 成为唯一正式业务实现。
- Rust 保留四个 crate，CLI 通过单一 core 处理入口完成内存业务流程。
- Python 只保留工作簿比较、合成输入和发布验收工具。
- 删除旧业务实现、旧 GUI、Phase 0/meta harness 和只保护退役实现的测试。
- 新增当前架构、工作簿契约和统一文档导航。
- 发布标签由 Cargo workspace 版本校验，不再只允许单个硬编码版本。

## 兼容性

除应用版本和旧 Python 入口退役外，以下内容保持兼容：

- Rust CLI 参数、默认路径、check-only 和禁止覆盖；
- 成功/失败 JSON、错误码和 `retryable`；
- 三张 Sheet 的顺序、字段、数值、样式和业务勾稽；
- GB/SK 独立成本项、白名单、异常阈值和 Decimal 语义；
- `RunManifestV1` 字段、路径脱敏、SHA-256 和原子发布；
- low-memory 触发条件和 Windows ZIP 布局。

## 验证要求

RC 只有在以下门禁全部通过后才可推送：

- Rust fmt、Clippy、全 workspace/全 feature 测试；
- Python 验证工具 Ruff、pytest 和合成 GB/SK；
- 真实 GB/SK 基线/候选 workbook 零差异；
- normal-mode N=5 wall、PWS 和输出大小；
- Windows ZIP 哈希、固定布局和无 Rust/Python child `PATH` smoke。

## 限制

- 这是发布候选，不自动代表正式版已批准。
- 推送标签和发布外部资产仍需要明确确认。
