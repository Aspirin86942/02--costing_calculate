# Costing Calculate v0.3.0

v0.3.0 是一次证据驱动的项目整理，不增加业务功能。

## 主要变化

- Rust 是唯一正式业务实现，Python 仅保留轻量验证工具。
- core 内存业务流程收敛为单一入口，CLI 不再编排内部阶段。
- 删除退役业务代码、历史 GUI 和大型迁移 harness。
- 统一项目提示词、README、架构、契约、性能、计划、变更和决策文档。
- 应用版本升级到 `0.3.0`；`RunManifestV1` schema 仍为 V1。
- 发布 workflow 从 Cargo workspace 读取版本并校验正式/RC 标签。

## 兼容性

Rust CLI、三张 Sheet、业务规则、JSON 错误模型、Manifest V1、原子发布、low-memory 行为和 Windows 包布局与 v0.2.0 保持兼容。唯一有意退役的是旧 Python 业务入口。

## 验证

正式标签只在 RC 完成 Rust/Python 公共门禁、真实 GB/SK 等价比较、性能/内存门禁和 Windows 包 smoke 后推送。

## 回滚

回滚时部署完整的上一版已验证 ZIP，不混用不同版本的可执行文件、配置、schema、示例或校验文件。整理前源码可从 `cleanup-baseline-2026-07-27` 恢复。
