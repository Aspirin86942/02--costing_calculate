# Costing Calculate v0.3.1-rc.1

本候选版提供两种 Windows x86-64 构建，解压即可运行。两份 ZIP 内的程序都叫 `costing-calculate.exe`，同时试用时请分别解压到两个目录。

| 下载文件 | 适用场景 |
| --- | --- |
| `costing-calculate-v0.3.1-rc.1-windows-x86_64.zip` | 常规版。完整 SK 开启 Manifest 时，实测峰值工作集比 PGO 版低约 56 MiB。 |
| `costing-calculate-v0.3.1-rc.1-windows-x86_64-pgo.zip` | PGO 版。使用合成工作簿训练，适合以处理速度为优先的日常批处理。 |

下载所选 ZIP 及同名的 `.sha256` 文件。可用 PowerShell 的 `Get-FileHash -Algorithm SHA256 <ZIP文件名>` 核对压缩包，解压后用 `.\costing-calculate.exe --version-json` 查看程序版本和源码提交。

本次修复低内存 SK 文件在桌面 Excel 中无法打开的问题，并压缩总表中可推导的单元格地址。Windows 完整 SK 普通写出实测从 71.88 MiB 缩至 30.52 MiB。以冻结的 0.3.1 为对照，独立五次的耗时中位数为 7.27 秒，常规优化版为 6.28 秒，PGO 版为 5.53 秒。两种构建均通过真实完整 SK 的 Excel 打开、另存及回读。[测试方法及全部结果](https://github.com/Aspirin86942/02--costing_calculate/blob/v0.3.1-rc.1/docs/changes/2026-11-20-windows-workbook-export.md)

Linux 源码可随标签获取。Linux 0.3.1 在真实完整 SK 上出现过段错误和内容差异，该场景仍待原生复验。[Linux 验收记录](https://github.com/Aspirin86942/02--costing_calculate/blob/v0.3.1-rc.1/docs/changes/releases/v0.3.1.md)
