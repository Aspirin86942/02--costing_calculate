# Costing Calculate v0.3.1-rc.2

此预发布提供 Windows x86-64 常规版和 PGO 版，两者都来自源码提交 `1b0cdfa`。两份 ZIP 内的程序均为 `costing-calculate.exe`，同时使用时请分别解压到两个目录。

| 下载文件 | 真实完整 SK 耗时 | 峰值工作集 |
| --- | ---: | ---: |
| `costing-calculate-v0.3.1-rc.2-windows-x86_64.zip` | 5.5509 秒 | 1,755.20 MiB |
| `costing-calculate-v0.3.1-rc.2-windows-x86_64-pgo.zip` | 4.9752 秒 | 1,750.82 MiB |

使用同一份 912,921 行的真实完整 SK，普通模式下各独立运行五次，表中为中位数。与上一候选版 `v0.3.1-rc.1` 在同机交错运行八对，常规版耗时缩短 1.60%，PGO 版缩短 3.06%，两者均在八对中全部更快。普通与带 Manifest 两种模式的四次工作簿比较均为零差异，两个新版的输出均通过桌面 Excel 打开、另存和回读。[完整复测记录](../2026-11-21-windows-full-sk-1b0cdfa.md)

每份 ZIP 均附同名 `.sha256` 文件，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256 <ZIP文件名>` 核对。两个包均通过隔离 PATH 下的 GB 和 SK 检查、工作簿生成与 Manifest 校验。[发布检查](https://github.com/Aspirin86942/02--costing_calculate/actions/runs/44855559450)
