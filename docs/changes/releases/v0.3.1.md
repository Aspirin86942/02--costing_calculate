# Costing Calculate 0.3.1

0.3.1 默认启用五项性能改动，沿用现有 GB/SK 命令、金额计算、三张结果表及 V1 审计格式。

- 大型单表 XLSX 按完整行并行读取并按原顺序合并，特殊布局交给原读取路径。
- 写出时共享已有文本，低内存模式在填充工作表的同时压缩行数据。
- 命令行使用 `mimalloc` 分配内存，退出时由系统回收展示表。可重复调用的 Rust 接口仍在每次调用后释放内存。

## 验收状态

0.3.1 正式源码通过 Rust 格式与静态检查、222 项 Rust 测试和 487 项 Python 测试。Linux 环境跳过一项 Windows 专用检查。受控 Excel 写出库的 83 个文件与登记哈希一致。

候选在真实 GB/SK 各两种模式和 27 个合成场景下通过了工作簿比对。一次完整 SK 审计运行记录到 42.38 秒和 18.61 秒。原版重复运行出现崩溃和数值差异，完整 SK 的稳定提速幅度仍待验证。Windows 原生构建、ZIP 运行检查和性能验收待完成。[完整实测记录](../2026-11-20-sk-speed.md)和[采用决策](../../decisions/2026-11-20-v0.3.1-performance.md)
