# 0.3.1 采用五项性能改动

2026-11-20 已采纳。维护者在审阅性能和正确性结果后，决定将五项 Linux 候选实现合入正式源码，生成 0.3.1 并提交。

保留独立候选程序即可继续实验。此次选择将同一套经功能比对的实现作为默认路径，使标准构建可以直接使用。CLI 参数、三张工作表和金额计算继续遵守[工作簿契约](../contracts/workbook.md)。

候选在真实 GB/SK 的四次比对和 27 个合成场景中通过。部分单项实验超过内存上限。完整 SK 的原版重复运行出现崩溃和超出容差的单元格差异，五项组合仍缺合格的八对测量及独立五次复测。Windows 发布包须在 Windows 上独立构建和验收。性能门槛与数值容差继续按[性能规则](../performance/README.md)执行。[实验数据](../changes/2026-11-20-sk-speed.md)
