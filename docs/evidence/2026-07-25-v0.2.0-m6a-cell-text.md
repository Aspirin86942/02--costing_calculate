# v0.2.0 M6A `cell_text` Experiment — 2026-07-25

## Decision

**Adopted.** The comparison-only borrowed text candidate exceeded the PRD
normalize gate, improved full-run wall time, stayed within PWS and output-size
gates, and produced zero contract or oracle mismatches.

Only `is_total_row` and `forward_fill_with_rules` use the new borrowed helper.
`format_period_value`, `normalize_period_key`, Decimal normalization, public
APIs, and all workbook/business contracts remain unchanged.

## Excluded attempts

Two driver-only attempts were excluded before the formal normal-mode dataset:

1. The first driver used PowerShell's automatic `$input` variable name and
   failed argument binding before the first formal child run.
2. A corrected driver initially placed the full workbook comparator between
   every timed pair. The first comparator was intentionally terminated after a
   read-only process check showed that this would add roughly 50 minutes of
   CPU-heavy work between timing samples. That attempt was excluded in full.

The final protocol isolated all five timing pairs from comparator load, then
ran the repository's official full GB/SK oracle once as a separate correctness
gate. Failed/terminated attempt directories remained ignored local diagnostics
and did not contribute any formal sample.

## Adoption rationale

The candidate removes avoidable `String` allocations exactly where the PRD
allowed them, while keeping owned conversions for period and Decimal paths.
The primary normalize threshold, full-wall guardrail, PWS, output size,
contracts, atomicity, and real oracle all pass. The candidate therefore remains
in the production source.
