## 固定规则

- 业务金额、工单归属、产品池、材料汇总、错误列表、三张 Sheet、CLI/Manifest 契约不变。
- 单元格容差 `1e-9`、列累计 `1e-8`；release、`codegen-units=1`、锁定依赖、无新增生产依赖。
- 同一文件同时只有一个执行者。工具预算节点仅修改 `autotune_experiment.py` 和其专用测试；主执行负责其它文件与集成。
- 初筛与验收使用 `external_wall_seconds`；日常无审计清单与审计模式分别比较。
- 每次校准 4 对、同一批次最多两次；失败时停止该批次排名，继续独立正确性工作。
- 候选 ≥8 对，主场景改善 ≥5%、胜出 ≥6/8；其它场景回退 ≤2%，内存、输出大小与非目标阶段沿用既有保护。
- 每批最多一个预登记组合；组件均通过后激活，组合对最佳单项额外改善 ≥2%。
- 真实完整 SK 使用独立预登记的资源场景；普通/Colab 场景维持原 2 GiB 预算和旧样本门槛。资源上限与采纳标准分别判断。
- Linux 与 Windows 的平台证据分开记录。没有 Windows 环境时保留未验证状态。
